MEDEVAX READY PRODUCT CATALOGUE

This package is prepared so you can replace product PNGs without changing the database mapping.

PROJECT-READY PATH
MedicalSupplies.Web/wwwroot/images/products/

There are 167 PNG files named exactly by product code:
MEV-001.png through MEV-167.png

EASIEST METHOD
1. Open the package.
2. Copy the entire "MedicalSupplies.Web" folder into the root of your project and allow it to merge/replace the existing wwwroot/images/products files.

The database seed is in:
database/MEDEVAX_product_images_seed.sql

The CSV mapping is in:
database/MEDEVAX_product_image_map.csv

The images are supplied catalogue assets (product illustrations and exploded-view images), not newly invented manufacturer packaging.
